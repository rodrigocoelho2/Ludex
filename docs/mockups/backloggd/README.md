# Backloggd-style mocks

The design that reviews, lists, the journal and Log a game were built from, made in Claude Design (Nov 2026). The
people, reviews and lists in them are the made-up demo accounts (Seed:DemoReviews).

| File | What it is |
| --- | --- |
| `Main.dc.html` | Home: trending this week, popular reviews (this week, friends, all time), popular lists, coming soon, sleeper hits. |
| `Game.dc.html` | A game: your log (status, half stars, platform, 100%), the spread of ratings, the counts, reviews with a spoiler warning, your journal and the lists it's in. |
| `Review.dc.html` | A review's own page: likes, comments, more from the author. |
| `Phone.dc.html` | Home on a phone. |
| `LogGame.dc.html` | The Log a game dialog. |
| `Profile.dc.html` | A profile: four favourites, ratings, finished per year, genres, recent reviews, activity. |
| `Journal.dc.html` | The journal: a month of sessions, a day's sessions, the month by game. |
| `Lists.dc.html` | A ranked list with your progress through it. |
| `canvas.json` | How the artboards sit on the canvas. |
